# Quellenverzeichnis

Folgende Quellen und Dokumentationen wurden für die Bearbeitung der Aufgabe verwendet:

1.  **Material Design 3 - Buttons**
    *   Thema: Gestaltung und Implementierung von modernen Buttons (MaterialButton) und deren Corner-Radius.
    *   URL: [https://m3.material.io/components/buttons/overview](https://m3.material.io/components/buttons/overview)

2.  **Android Developers - Dark Theme**
    *   Thema: Erzwingen des dunklen Designs unabhängig von Systemeinstellungen via `AppCompatDelegate`.
    *   URL: [https://developer.android.com/guide/topics/ui/look-and-feel/darktheme](https://developer.android.com/guide/topics/ui/look-and-feel/darktheme)

3.  **Android Developers - GridLayout**
    *   Thema: Strukturierung der Taschenrechner-Oberfläche mittels Grid-Systemen.
    *   URL: [https://developer.android.com/reference/android/widget/GridLayout](https://developer.android.com/reference/android/widget/GridLayout)

4.  **Android Developers - Haptic Feedback**
    *   Thema: Implementierung von taktilem Feedback (`VIRTUAL_KEY`) zur Verbesserung der User Experience.
    *   URL: [https://developer.android.com/reference/android/view/HapticFeedbackConstants](https://developer.android.com/reference/android/view/HapticFeedbackConstants)

5.  **Android Developers - Support different screen sizes**
    *   Thema: Optimierung der UI für Tablets durch die Nutzung von Ressourcen-Qualifizierern wie `sw600dp`.
    *   URL: [https://developer.android.com/guide/topics/ui/screens-distribution](https://developer.android.com/guide/topics/ui/screens-distribution)

6.  **exp4j - Expression Builder for Java**
    *   Thema: Mathematische Formelauswertung und Parsing für die Taschenrechner-Logik.
    *   URL: [https://www.objecthunter.net/exp4j/](https://www.objecthunter.net/exp4j/)

Für die Verschönerung vom Quellverzeichnis sowie Wissenslücken wurde KI genutzt.
